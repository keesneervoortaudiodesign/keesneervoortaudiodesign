Time Syncfor Phase-Accurate Measurement

A transfer curve becomes an impulse response only if it carries phase — and phase is time. Metrao3 keeps time on its own plane: a GPS PPS clock at the node and PTP across the LAN. The link a node happens to use never touches the phase.
