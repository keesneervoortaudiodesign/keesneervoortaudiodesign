How the ten become one

src/data/curve-math.ts → computeGroupAverage()
Magnitude
10·log₁₀( mean( 10^(dBᵢ/10) ) )
Energy average, not a dB average. Power is what sums physically, so a deep notch in one capture cannot drag the mean down with it.
Phase
atan2( Σsinφᵢ , Σcosφᵢ )
Circular mean. Averaging wrapped angles arithmetically would put the mean of +179° and −179° at zero; this puts it at 180°.
Coherence
mean( γ²ᵢ )
Plain arithmetic mean. It stays a quality figure for the set — where the ten disagree, it falls, and those bins are the ones to distrust.
Impulse response
mean( hᵢ[n] )
Sample-by-sample mean, which only holds because every capture was already delay-compensated to the same 10 ms margin.
Group members
Curves interpolated to the first member's frequency grid · auto-delay on, IR peak parked at 10 ms · smoothing off (raw bins) · magnitude window −30 … +15 dB Traces are representative example data, not a real capture set — export the group as CSV to plot the real thing.
